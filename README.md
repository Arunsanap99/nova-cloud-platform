## ✨ Features

- **Clean & Minimalist Aesthetic**: Refined typography using *Plus Jakarta Sans* and *Inter* with balanced visual hierarchy.
- **Dynamic Color Modes**: Smooth toggle between *Dark Slate* and *Light Porcelain* themes with system preference detection.
- **Interactive Code Playground**: Tabbed interactive code snippets (`cluster.ts`, `mesh.py`, `deploy.sh`) with 1-click clipboard copy.
- **Responsive Bento Grid**: Modern asymmetric cards featuring multi-cloud route monitoring, ephemeral PR staging, AI telemetry, and FinOps metrics.
- **Interactive Architecture Flow**: Visual GitOps continuous deployment pipeline diagram.
- **Interactive Billing Toggle**: Live dynamic price switching for monthly and annual billing with discount calculation.
- **Accessible & Tested**: Semantic HTML5 markup, smooth scroll spy navigation, keyboard accessibility, and zero external JS dependencies.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic tags, OpenGraph meta properties, responsive viewport configuration.
- **CSS3**: Vanilla CSS with custom properties (CSS variables), CSS Grid, Flexbox, glassmorphism, and responsive breakpoints.
- **JavaScript**: Modular Vanilla JS (ES6+) for theme persistence, card spotlights, animated counters, FAQ accordions, and form validation.
- **Hosting**: Deployed on [Vercel](https://vercel.com) with global edge delivery and continuous deployment.
- **Icons & Fonts**: Font Awesome 6, Google Fonts (Plus Jakarta Sans, Inter, JetBrains Mono).
