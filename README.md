# NovaEngine — Modern Responsive Landing Page

A premium, high-performance, and responsive developer cloud platform landing page built with **HTML5**, **CSS3**, and **Vanilla JavaScript**.

![NovaEngine Preview](https://images.unsplash.com/photo-1550751827-4bd374c3f58b?auto=format&fit=crop&w=1200&q=80)

---

## ⚡ Features

- **Cutting-Edge Typography:** Utilizes Google Fonts (`Syne`, `Space Grotesk`, `Plus Jakarta Sans`, and `JetBrains Mono`).
- **Cyber Aesthetic & Ambient Mesh:** Glowing animated radial backdrops, cybernetic scanlines, and glassmorphic elevation.
- **Dynamic Spotlight Cards:** Mouse-following specular spotlight glow on feature cards.
- **Interactive Code Switcher:** Live syntax-highlighted code console supporting TypeScript, Python, and Shell with one-click clipboard copy.
- **Asymmetric Bento Grid:** Modern responsive layout showcasing key architecture primitives.
- **Theme Switcher:** Seamless Dark Obsidian and Light Porcelain theme toggle with `localStorage` persistence and OS preference detection.
- **Animated Performance Metrics:** Eased counter animation using `requestAnimationFrame` and `IntersectionObserver`.
- **Interactive FAQ Accordion:** Accessible and animated single-expand accordion.
- **Dynamic Pricing Calculator:** Interactive Monthly vs. Annual toggle with discount pill calculation.
- **Validated Contact Form:** Client-side input validation with animated loading spinner and custom toast notifications.
- **Zero Frameworks:** 100% Vanilla HTML5, CSS3, and JavaScript with zero external runtime dependencies.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Arunsanap99/la.git
cd la
```

### 2. Run Locally
Open `index.html` in your browser, or run a local web server:

#### Using VS Code:
1. Install the **Live Server** extension.
2. Right-click `index.html` and select **Open with Live Server**.

#### Using Python:
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.
